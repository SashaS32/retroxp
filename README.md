# RetroXP 1.0 — прототип интеграции v86

Загрузите содержимое архива в корень GitHub Pages.

## ISO
Создайте папку `assets` и поместите туда ISO, который вы имеете право использовать, назвав его `windows-xp.iso`. Образ намеренно не включён в архив.

## Важные ограничения
- Это прототип подключения эмулятора, а не гарантированно рабочая готовая XP.
- ISO подключается как CD-ROM. Для установки потребуется виртуальный жёсткий диск; этот прототип его автоматически не создаёт.
- Совместимость Windows XP с v86 не гарантируется; особенно это касается 64-битной версии XP. Для теста вероятнее подойдёт 32-битный x86 ISO.
- Библиотека v86 и BIOS загружаются с copy.sh, поэтому нужен интернет и доступность этого сервиса.
- Не публикуйте Windows XP ISO без соответствующих прав. GitHub Pages — статический хостинг; большой образ лучше хранить отдельно, если у вас есть право его размещать.
