# RetroXP 1.0 — v86 prototype (без сейвстейта)

Это статическая страница для GitHub Pages с подключением браузерного эмулятора v86. Сохранённое состояние пользователя намеренно не включено.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` через локальный веб-сервер или опубликуйте файлы в GitHub Pages.
3. Выберите собственный совместимый образ установленного виртуального диска (`.img`, `.bin`, `.hdd`, `.vhd`).
4. Нажмите «Запустить Windows XP».

Нужен образ именно установленной системы. ISO установщика — это установочный носитель, а не готовый системный диск. Совместимость Windows XP с v86 зависит от конфигурации виртуальной машины и драйверов; успешная загрузка не гарантируется без проверки конкретного образа.

## Важно
- Образ диска выбирается локально и читается в памяти браузера; код страницы не отправляет его на сервер.
- Не публикуйте личные образы дисков, сейвстейты, пароли или ключи Windows в открытом репозитории.
- Для публичного сервиса нельзя раздавать Windows XP или ключи без соответствующих прав.
- Это прототип запуска одной локально выбранной машины, а не многопользовательская облачная инфраструктура.

## Технология и лицензия
Используется v86: https://github.com/copy/v86 (Simplified BSD License / BSD-2-Clause). Библиотека и BIOS загружаются с `copy.sh`; для полностью автономного размещения скачайте официальный release v86 и разместите его `libv86.js`, WASM и BIOS-файлы на своём хостинге, затем обновите пути в `index.html` и `script.js`.


## Мобильный режим
Интерфейс адаптируется к телефонам, поддерживает полноэкранный режим (кнопки «На весь экран» и «Экран XP») и удобные сенсорные кнопки. Для комфортной работы с Windows XP рекомендуется альбомная ориентация. Полноэкранный режим зависит от поддержки браузером.
