# RetroXP 1.0 — ISO-only

Сборка загружает `iso/windows-xp.iso` автоматически и подключает его как CD/DVD в v86. Виртуальный жёсткий диск (`.img`) намеренно не подключён.

## Установка
1. Положи разрешённый к распространению ISO в `iso/` и назови файл `windows-xp.iso`.
2. Загрузи всё содержимое папки `retroxp-mobile` в корень GitHub Pages репозитория.
3. Открой сайт. Он автоматически попробует получить `iso/windows-xp.iso`.
4. Если ISO не найден, его можно выбрать кнопкой «Выбрать ISO».

## Ограничение
Без виртуального жёсткого диска Windows XP Setup может загрузиться с CD, но установить Windows на диск будет некуда. Это вариант для загрузки/проверки ISO, не готовая установленная XP.

Библиотека v86 загружается с CDN. Интернет требуется.
