# RetroXP 1.0 — компьютер и телефон

Адаптивная оболочка для браузерной эмуляции x86 с нижней панелью клавиш/мыши.

## Подключение файлов
- `Выбрать диск (.img)` — выбирает виртуальный жёсткий диск, который подключается как IDE primary master.
- `Выбрать ISO` — подключает ISO как CD/DVD.
- `Папка с ISO` — позволяет выбрать папку; приложение ищет файлы с расширением `.iso` без привязки к имени файла. Если найдено несколько ISO, можно выбрать нужный по номеру.

Выбор папки работает в браузерах, поддерживающих `webkitdirectory` (обычно настольный Chrome/Edge). На телефоне можно использовать кнопку `Выбрать ISO`, если браузер не поддерживает выбор папки.

Важно: сайт не может самовольно просматривать папки компьютера. Пользователь должен сам выбрать файл или папку в системном окне. Файлы читаются локально и не отправляются на GitHub.

Для загрузки уже установленной Windows нужен совместимый загрузочный образ виртуального жёсткого диска `.img`. Для установки из ISO нужен отдельный пустой виртуальный диск `.img`; ISO подключается как CD/DVD. ISO установщика сам по себе не является установленной Windows. Совместимость конкретного ISO и диска не гарантируется.

Не публикуйте образы Windows или ключи активации в открытом репозитории без соответствующих прав.
