# RetroXP 1.0

Стартовая оболочка проекта RetroXP — сайта для запуска гостевой ОС в браузере.

## Публикация на GitHub Pages

1. Загрузите все файлы из архива в корень репозитория `retroxp`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Подождите публикации и откройте выданный GitHub Pages URL.

## Важно

Сейчас это только главная страница, а не работающая виртуальная машина. Для настоящего запуска потребуется отдельно интегрировать браузерный эмулятор, совместимый образ/виртуальный диск и загрузочные данные. Не включайте в публичный репозиторий Windows ISO, виртуальный диск или другие материалы, если лицензия не разрешает их распространение.

Windows XP является продуктом Microsoft. RetroXP — независимый неофициальный проект.
