О ПРОЕКТЕ

Не симулятор, а эмуляция

Цель RetroXP — запускать гостевую операционную систему в браузере с помощью программной эмуляции. Этот шаблон пока содержит только сайт-оболочку; он не включает Windows, BIOS или виртуальный диск.

СЛЕДУЮЩИЙ ЭТАП

Подключение виртуального компьютера

  1. Выбрать эмулятор, совместимый с нужной архитектурой и конфигурацией XP.
  2. Подготовить виртуальный диск и загрузочные файлы в поддерживаемом формате.
  3. Проверить запуск локально и только затем публиковать на GitHub Pages.
