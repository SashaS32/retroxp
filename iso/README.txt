ПАПКА ДЛЯ ISO

Положи сюда ISO-образ, переименовав его в:
windows-xp.iso

Итоговый путь должен быть:
retroxp-mobile/iso/windows-xp.iso

Сайт автоматически попробует загрузить этот файл при открытии.
В архиве намеренно нет образа Windows XP. Добавляй только ISO,
который ты вправе хранить и распространять через публичный сайт.

Важно: эта сборка подключает ISO как CD/DVD и НЕ создаёт виртуальный
жёсткий диск. Установщик Windows XP может загрузиться, но установить
систему без отдельного виртуального диска не сможет.
